# Backend ArsipSemantik

Folder ini digunakan untuk backend FastAPI.

Rencana struktur:

- `app/api/routes/` untuk endpoint API
- `app/core/` untuk konfigurasi aplikasi
- `app/database/` untuk koneksi PostgreSQL + pgvector
- `app/models/` untuk model database
- `app/schemas/` untuk validasi request/response
- `app/services/` untuk logika auth, dokumen, search, dan evaluasi
- `app/utils/` untuk helper umum
- `tests/` untuk pengujian backend
