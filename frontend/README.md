# ArsipSemantik Frontend

Frontend ArsipSemantik menggunakan React.js, Vite, Tailwind CSS, React Router DOM, dan Axios.

## Cara Menjalankan

```bash
cd frontend
npm install
npm run dev
```

Buka browser:

```text
http://127.0.0.1:5173
```

## Struktur Awal

- `src/components` untuk komponen UI reusable.
- `src/layouts` untuk layout admin dan mahasiswa.
- `src/pages` untuk halaman login, pencarian, dashboard admin, repository, dan evaluasi.
- `src/routes` untuk konfigurasi routing.
- `src/services` untuk integrasi API FastAPI.
- `src/utils` untuk helper kecil.
